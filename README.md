# BotIbero 🤖🌱

Bot de Telegram desarrollado en Python para el monitoreo automatizado de parámetros ambientales en huertos y camas de cultivo mediante dispositivos IoT (ESP32).

## Funcionalidades
- Lectura en tiempo real de sensores de Temperatura, Humedad, Presión, Calidad del Aire y Humedad de Suelo.
- Notificaciones y evaluación de estado mediante semáforos ambientales.
- Generación de gráficas históricas.
- Captura de fotografía remota.

## Tecnologías
- Python (python-telegram-bot, matplotlib, pandas)
- Flask (Recepción de telemetría IoT)
- Hardware: ESP32, BME688, FC-28

*(Este repositorio contiene el código fuente de la interfaz del bot en Telegram).*
